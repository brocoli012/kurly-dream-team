# Dream Team Worker 규칙

> 이 파일은 .claude/rules/에 위치하여 모든 에이전트에게 자동 주입됩니다.

## Worker Preamble (서브에이전트 필수)

### 금지 사항
- Task tool로 추가 서브에이전트 생성 금지
- 다른 에이전트에게 재위임 금지
- 추측 기반 완료 선언 금지

### 필수 사항
- Read/Write/Edit/Bash 직접 사용
- 절대 경로로 결과 보고
- 증거 기반 완료 (빌드/테스트 결과 포함)

### 구현 완료 시 필수 기록
- [ ] 변경 파일 목록 (절대 경로)
- [ ] 변경 요약 (3줄 이내)
- [ ] 티켓 상태 업데이트
